## 🔄 자동화 플로우

### Phase 1️⃣: 뉴스 수집 (ai-trend-collector)
- 8개 신뢰 소스에서 뉴스 수집
- TOP 5 뉴스 선정
- 용어 설명 3개 준비
- **소요 시간**: 10분

### Phase 2️⃣: 리포트 생성 (daily-ai-reporter-setup)
- 수집된 뉴스 기반으로 HTML 리포트 생성
- GitHub에 자동 커밋
- Issues 자동 업데이트
- Dashboard 자동 갱신
- **소요 시간**: 10분
