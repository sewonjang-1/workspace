# Daily AI Workflow

AI 뉴스 수집부터 리포트 생성까지 **완전 자동화된 엔드-투-엔드 워크플로우**입니다.

## 🎯 워크플로우의 목적

```
자동화 완성도: 100%
수동 개입: 0%
```

- 📰 **AI 뉴스 자동 수집** (ai-trend-collector)
- 📄 **리포트 자동 생성** (daily-ai-reporter-setup)
- 📤 **GitHub 자동 푸시** (매일 반복)

---

### **매일 아침 09:00 AM**

              ↓

│  ✅ 리포트 생성 성공                            │

## 📊 데이터 흐름

### **Phase 1 → Phase 2로의 데이터 전달**

```
[ai-trend-collector 출력]
├─ TOP 5 뉴스
│  ├─ 제목
│  ├─ 설명
│  ├─ 왜 중요한가
│  └─ 링크
├─ 용어 설명 3개
│  ├─ 용어명
│  └─ 설명
├─ 국내외 트렌드 요약
└─ 메타데이터
      ↓ [자동 수신]
[daily-ai-reporter-setup]
├─ 입력 데이터 검증
├─ HTML 템플릿에 맞춰 정렬
├─ 최종 리포트 생성
├─ GitHub 커밋
├─ Issues 자동 댓글
└─ Dashboard 업데이트
```

## 📋 각 스킬의 역할

### **🔵 Phase 1: ai-trend-collector**

| 항목 | 내용 |
|------|------|
| **목적** | AI 뉴스 수집 & 분석 |
| **실행 시간** | 09:00 - 09:10 AM |
| **출력** | 뉴스 5개 + 용어 설명 3개 |
| **웹 소스** | 8개 한정 (신뢰도 보증) |
| **데이터 형식** | JSON / 구조화된 데이터 |

### **🟢 Phase 2: daily-ai-reporter-setup**

| 항목 | 내용 |
|------|------|
| **목적** | 리포트 생성 & GitHub 푸시 |
| **실행 시간** | 09:10 - 09:20 AM |
| **입력** | Phase 1 출력 데이터 |
| **출력** | HTML 파일 + Git 커밋 |
| **자동화** | Issues 댓글, Dashboard 업데이트 |

## ✅ 에러 처리

### **Phase 1 실패 시**
```
❌ ai-trend-collector 실패
├─ 재시도 1: 5분 후
├─ 재시도 2: 10분 후
└─ 최종 실패: Issue에 자동 알림
```

### **Phase 2 실패 시**
```
❌ daily-ai-reporter-setup 실패
├─ Phase 1 결과는 캐시됨
├─ 재시도: Phase 2만 반복
└─ 최종 실패: Issue에 상세 알림
```

### **완전 실패 시**
```
❌ 전체 워크플로우 실패
├─ Issue #3 자동 댓글 (에러 상세)
├─ Dashboard 상태 업데이트
└─ 다음날 09:00 AM 자동 재시도
```
