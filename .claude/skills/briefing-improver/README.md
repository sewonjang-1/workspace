## 🔄 자동화 브리핑 프로세스

### Phase 1️⃣: 뉴스 수집 & 분석 (ai-trend-collector)
- 8개 신뢰 소스에서 뉴스 자동 수집
- 중복 제거 및 신뢰도 검증
- TOP 5 뉴스 선정
- 용어 설명 3개 준비
- **소요 시간**: 10분

### Phase 2️⃣: 브리핑 생성 & 게시 (daily-ai-reporter-setup)
- 수집된 데이터를 전문 브리핑으로 가공
- HTML 브리핑 문서 생성
- GitHub에 자동 커밋 & 푸시
- Issues 자동 업데이트
- Dashboard 자동 갱신
- **소요 시간**: 10분
