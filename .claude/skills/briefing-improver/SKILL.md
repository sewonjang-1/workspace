# Briefing Improver

AI 동향을 **자동 수집 → 정리 → 브리핑 생성**하는 완전 자동화 스킬입니다.

## 🎯 브리핑 개선기의 목적

```
자동화 완성도: 100%
수동 개입: 0%
정보 신뢰도: 99%
```

- 📰 **AI 뉴스 자동 수집** (ai-trend-collector)
- 📋 **전문 브리핑 생성** (daily-ai-reporter-setup)
- 📤 **GitHub 자동 게시** (매일 반복)

---

## 📊 브리핑 데이터 흐름

### **Phase 1 → Phase 2로의 데이터 구성**

```
[ai-trend-collector 출력 (브리핑 원본)]
├─ TOP 5 뉴스
│  ├─ 제목
│  ├─ 설명
│  ├─ 왜 중요한가
│  └─ 출처 링크
├─ 용어 설명 3개
│  ├─ 신규 용어
│  ├─ 일반인 설명
│  └─ 활용 예시
├─ 국내외 트렌드 분석
└─ 신뢰도 메타데이터
      ↓ [자동 수신]
[daily-ai-reporter-setup]
├─ 입력 데이터 검증
├─ 브리핑 템플릿 적용
├─ 전문 포맷 정렬
├─ 최종 HTML 브리핑 생성
├─ GitHub 자동 커밋
├─ Issues 자동 댓글
└─ Dashboard 리포트 업데이트
```

## 📋 각 스킬의 역할

### **🔵 Phase 1: ai-trend-collector**

| 항목 | 내용 |
|------|------|
| **목적** | 브리핑 원본 데이터 수집 & 분석 |
| **실행 시간** | 09:00 - 09:10 AM |
| **입력** | 8개 신뢰 웹 소스 |
| **출력** | 뉴스 5개 + 용어 설명 3개 + 트렌드 |
| **데이터 형식** | JSON / 구조화된 브리핑 데이터 |
| **신뢰도** | 검증된 소스만 (99%) |

### **🟢 Phase 2: daily-ai-reporter-setup**

| 항목 | 내용 |
|------|------|
| **목적** | 브리핑 생성 & GitHub 게시 |
| **실행 시간** | 09:10 - 09:20 AM |
| **입력** | Phase 1 브리핑 데이터 |
| **출력** | HTML 브리핑 + Git 커밋 |
| **자동화** | Issues 댓글, Dashboard 업데이트 |
| **배포** | GitHub 저장소에 자동 게시 |

## ✅ 에러 처리

### **Phase 1 실패 시**
```
❌ ai-trend-collector 실패
├─ 원인 분석: 웹 소스 접근 오류
├─ 재시도 1: 5분 후
├─ 재시도 2: 10분 후
└─ 최종 실패: Issue에 자동 알림
```

### **Phase 2 실패 시**
```
❌ daily-ai-reporter-setup 실패
├─ Phase 1 결과는 캐시됨
├─ 재시도: Phase 2만 반복
└─ 최종 실패: Issue에 상세 에러 기록
```

### **완전 실패 시**
```
❌ 전체 브리핑 파이프라인 실패
├─ Issue #3에 상세 에러 기록
├─ Dashboard에 실패 상태 표시
└─ 다음날 09:00 AM 자동 재시도
```
