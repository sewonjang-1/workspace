# AI Trend Collector

매일 아침 AI 동향을 자동으로 수집하고 분석하는 전문 스킬입니다.

## 이 스킬의 목적

- 🔍 **AI 뉴스 수집**: 전 세계 AI 관련 최신 뉴스 자동 수집
- 📊 **동향 분석**: 단순 정보가 아닌 맥락있는 분석 제공
- 🎓 **쉬운 설명**: 전문가가 아닌 사람도 이해할 수 있게
- 📈 **정기 제공**: 매일 아침 자동으로 정리

---

## 스킬이 하는 일

### 1️⃣ **AI 뉴스 수집**
```
매일 아침 9시에:
├─ 국제 AI 뉴스 (OpenAI, Google, Meta 등)
├─ 국내 AI 뉴스 (한국 AI 산업)
├─ 학술/기술 동향 (새로운 논문, 기술)
└─ 기업 동향 (투자, 인수합병)
```

### 2️⃣ **동향 분석**
```
수집한 뉴스를 다음 기준으로 분류:
├─ 임팩트: 얼마나 중요한가?
├─ 카테고리: 어떤 분야인가?
├─ 영향도: 일반인에게 얼마나 영향을 미치나?
└─ 트렌드: 큰 흐름이 뭔가?
```

### 3️⃣ **쉬운 설명**
```
각 뉴스를:
├─ 제목 (한눈에 이해)
├─ 한두 문장 설명
├─ 왜 중요한가?
└─ 일반인을 위한 용어설명
```

### 4️⃣ **정기 제공**
```
매일 아침 리포트:
├─ 📧 이메일/메시지
├─ 📄 HTML 리포트
├─ 📊 대시보드 업데이트
└─ 🔔 중요 뉴스 알림
```

## 사용 시나리오

### 시나리오 1: 일반인
```
사용자: "요즘 AI 뉴스가 뭐가 있어?"

스킬이 하는 일:
1. 최근 1주일 AI 뉴스 검색
2. 가장 임팩트 있는 뉴스 5개 선정
3. 각각을 쉬운 말로 설명
4. HTML 리포트로 제공

결과: "아, 이런 일이 있었구나" 하면서 이해
```

### 시나리오 2: 교육 담당자
```
사용자: "학생들한테 설명할 AI 뉴스 정리해줄래?"

스킬이 하는 일:
1. 교육적 가치가 있는 뉴스 수집
2. 학생 수준에 맞게 설명
3. 예시 포함
4. 실습 자료로 활용 가능한 형태

결과: 수업에서 바로 사용 가능한 자료
```

### 시나리오 3: 회사 임원
```
사용자: "매일 아침 AI 동향을 이사님 용으로 정리해줄래?"

스킬이 하는 일:
1. 비즈니스 관점의 뉴스 수집
2. 경영 임팩트 분석
3. 기회/위협 분석
4. 액션 아이템 제안

결과: 의사결정에 필요한 정보 제공
```

## 🌐 웹 수집 소스 (8개 한정)

> 정확성과 신뢰도를 위해 엄선된 8개 소스에서만 수집합니다.

### 📰 **지정된 웹 수집 소스**

| # | 소스 | 분야 | 업데이트 |
|---|------|------|---------|
| 1 | **OpenAI 공식 블로그** | ChatGPT, GPT 모델 | 주 2-3회 |
| 2 | **Google DeepMind 블로그** | Gemini, 기초 연구 | 주 1-2회 |
| 3 | **HackerNews (AI 섹션)** | 기술 뉴스 종합 | 일 10-20개 |
| 4 | **TechCrunch (AI 섹션)** | 스타트업, 투자 | 일 5-10개 |
| 5 | **뉴스1 / 연합뉴스 (AI 섹션)** | 국내 AI 뉴스 | 일 3-5개 |
| 6 | **ArXiv (AI 분야)** | AI 학술 논문 | 일 50+ 논문 |
| 7 | **Papers with Code** | 새 모델 & 코드 | 일 10+ 논문 |
| 8 | **Reddit r/MachineLearning** | AI 커뮤니티 | 일 20+ 게시물 |

### 🎯 **각 소스별 역할**

```
1️⃣ OpenAI 블로그
   → ChatGPT, GPT 최신 업데이트
   → 공식 발표 및 기술 해설

2️⃣ Google DeepMind 블로그
   → Gemini 관련 뉴스
   → AI 기초 연구 논문

3️⃣ HackerNews
   → 업계 핫 이슈 종합
   → 개발자 커뮤니티 반응

4️⃣ TechCrunch
   → AI 스타트업 소식
   → 투자 및 인수합병

5️⃣ 국내 뉴스 매체
   → 한국 AI 정책
   → 국내 기업 뉴스

6️⃣ ArXiv
   → 최신 학술 논문
   → 미래 기술 트렌드

7️⃣ Papers with Code
   → 실제 구현된 모델
   → 비교 가능한 성능 지표

8️⃣ Reddit
   → 커뮤니티 의견
   → 실제 활용 사례
```

### 📊 **수집 프로세스**

```
매일 09:00 AM
  ↓
[8개 소스 병렬 검색]
  ├─ Source 1: OpenAI 블로그 검색
  ├─ Source 2: Google DeepMind 블로그 검색
  ├─ Source 3: HackerNews 크롤링
  ├─ Source 4: TechCrunch 크롤링
  ├─ Source 5: 국내 뉴스 검색
  ├─ Source 6: ArXiv 최신 논문
  ├─ Source 7: Papers with Code 최신
  └─ Source 8: Reddit 트렌딩
  ↓
[결과 통합]
  - 중복 제거
  - 신뢰도 검증
  - 우선순위 정렬
  ↓
[TOP 5 뉴스 선정 및 정리]
```

### ✅ **신뢰도 기준**

- ✅ **신뢰**: 공식 발표, 검증된 소스
- ✅ **최신**: 24시간 이내 정보
- ✅ **다양성**: 여러 각도의 정보
- ❌ **제외**: 미검증 루머, 낡은 정보, 광고성 콘텐츠

## 주의사항

### ⚠️ 신뢰도
- 모든 뉴스는 신뢰도 높은 소스에서만

- GitHub에 자동 저장
